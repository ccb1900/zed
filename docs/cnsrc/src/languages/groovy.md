# Groovy

问题反馈请至：[https://github.com/valentinegb/zed-groovy/issues](https://github.com/valentinegb/zed-groovy/issues)

- 语法分析器：[murtaza64/tree-sitter-groovy](https://github.com/murtaza64/tree-sitter-groovy)  
- 语言服务器：[GroovyLanguageServer/groovy-language-server](https://github.com/GroovyLanguageServer/groovy-language-server)
