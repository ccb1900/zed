# Roc

[Roc](https://www.roc-lang.org/) 是一门快速、友好、函数式的编程语言。

Zed 编辑器中的 Roc 语言支持由社区维护的 [Roc 扩展](https://github.com/h2000/zed-roc)提供。
问题反馈请至：[https://github.com/h2000/zed-roc/issues](https://github.com/h2000/zed-roc/issues)

- 语法分析器：[faldor20/tree-sitter-roc](https://github.com/faldor20/tree-sitter-roc)
- 语言服务器：[roc-lang/roc/tree/main/crates/language_server](https://github.com/roc-lang/roc/tree/main/crates/language_server)

## 环境配置

1. 按照 Roc-Lang 官网的 [Roc 安装指南](https://www.roc-lang.org/install)进行操作
2. 确保 `roc` 和 `roc_language_server` 已加入您的 PATH 环境变量
