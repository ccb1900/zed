# Emmet

通过 [Emmet 扩展](https://github.com/zed-extensions/emmet) 可获得 Emmet 支持。

[Emmet](https://emmet.io/) 是一款网络开发者工具包，能极大优化 HTML 与 CSS 工作流程。

- 语言服务器：[olrtg/emmet-language-server](https://github.com/olrtg/emmet-language-server)
