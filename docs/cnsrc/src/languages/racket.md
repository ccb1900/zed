# Racket

Racket 语言支持可通过 [Racket 扩展](https://github.com/zed-extensions/racket)实现。

- 语法解析器：[zed-industries/tree-sitter-racket](https://github.com/zed-industries/tree-sitter-racket)

Zed 目前暂未支持 [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html)，更多信息请参阅 [Issue #15789](https://github.com/zed-industries/zed/issues/15789)。
