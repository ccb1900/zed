# Astro

对 Astro 的支持可通过 [Astro 扩展](https://github.com/zed-extensions/astro)获得。

- 语法解析器：[virchau13/tree-sitter-astro](https://github.com/virchau13/tree-sitter-astro)
- 语言服务器：[withastro/language-tools](https://github.com/withastro/language-tools)
