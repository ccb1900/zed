# Docker

Zed 对 `Dockerfile` 和 `docker-compose.yaml` 的支持由社区维护的扩展提供。

## Docker Compose

Zed 中的 Docker `compose.yaml` 语言支持由 [Docker Compose 扩展](https://github.com/eth0net/zed-docker-compose)提供。请将问题反馈至：[https://github.com/eth0net/zed-docker-compose/issues](https://github.com/eth0net/zed-docker-compose/issues)。

- 语言服务器：[microsoft/compose-language-service](https://github.com/microsoft/compose-language-service)

## Dockerfile

Zed 中的 `Dockerfile` 语言支持由 [Dockerfile 扩展](https://github.com/d1y/dockerfile.zed)提供。请将问题反馈至：[https://github.com/d1y/dockerfile.zed/issues](https://github.com/d1y/dockerfile.zed/issues)。

- 语法分析器：[camdencheek/tree-sitter-dockerfile](https://github.com/camdencheek/tree-sitter-dockerfile)
- 语言服务器：[rcjsuen/dockerfile-language-server](https://github.com/rcjsuen/dockerfile-language-server)
