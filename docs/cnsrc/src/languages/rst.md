# ReStructuredText (rst)

Zed 编辑器中的 ReStructuredText 语言支持由社区维护的 [reST 扩展](https://github.com/elmarco/zed-rst)提供。
问题反馈请至：[https://github.com/elmarco/zed-rst/issues](https://github.com/elmarco/zed-rst/issues)

- 语法分析器：[stsewd/tree-sitter-rst.git](https://github.com/stsewd/tree-sitter-rst.git)
- 语言服务器：[swyddfa/esbonio](https://github.com/swyddfa/esbonio)
