# 隐私与安全

## 核心理念

Zed 致力于仅收集为产品提供服务与持续优化所必需的最少量数据。

我们坚信，构建人工智能产品时应默认采用自愿加入的数据共享机制，而非像多数竞争对手那样默认选择退出。隐私模式并非一个需要手动开启的选项，而是我们与生俱来的基本原则。

作为开源产品，我们秉持最大程度的透明度原则，诚邀您审阅我们的代码库。若发现任何问题，欢迎随时向我们反馈。

您完全可以在不与 Zed 共享任何数据、不进行身份验证的情况下使用 Zed 的全部功能，包括人工智能服务。我们将始终全力支持这种使用方式。
