## 使用说明 {#usage}

所有通过Zed托管的模型调用将按Zed价格（上表最右侧列）计费。关于托管模型的使用方案与限制详情，请参阅[方案与用量](./plans-and-usage.md)。

> 我们建议您在离开智能体面板开始工作前，仔细考量最适合需求的模型。所有大语言模型都可能陷入“思维漩涡”，偶尔会出现需要人工干预的无限循环情况。

## 上下文窗口 {#context-windows}

上下文窗口是指大语言模型单次处理文本与代码的最大容量范围，该范围同时包含输入提示词与模型生成的输出内容。

| 模型               | 提供商    | Zed托管上下文窗口容量 |
| ------------------ | --------- | --------------------- |
| Claude Opus 4.1    | Anthropic | 200k                  |
| Claude Sonnet 4    | Anthropic | 200k                  |
| Claude Sonnet 3.7  | Anthropic | 200k                  |
| GPT-5              | OpenAI    | 400k                  |
| GPT-5 mini         | OpenAI    | 400k                  |
| GPT-5 nano         | OpenAI    | 400k                  |
| Gemini 2.5 Pro     | Google    | 200k                  |
| Gemini 2.5 Flash   | Google    | 200k                  |

> 我们计划在近期为托管的Sonnet 4和Gemini 2.5 Pro/Flash模型扩展支持的上下文窗口容量。敬请期待！

Zed中的每个智能体线程和文本线程都维护着独立的上下文窗口。
会话中包含的提示词、附加文件和回复越多，上下文窗口的容量就会越大。

为获得最佳效果，建议采用基于任务目标的方式管理智能体线程，为每项独立任务开启新线程。
