# 工具集

Zed智能助手配备多种工具，可帮助您与代码库交互并执行各类任务。

## 读取与搜索工具

### `diagnostics`

获取指定文件或整个项目的错误与警告信息，适用于代码修改后判断是否需要进一步调整。

### `fetch`

获取URL链接内容并以Markdown格式返回，便于将文档资料作为上下文参考。

### `find_path`

通过通配符模式（如“*_/_.js”）快速查找文件，按字母顺序返回匹配的文件路径。

### `grep`

使用正则表达式全局搜索文件内容，特别适合在未知具体文件路径时定位代码符号。

### `list_directory`

列出指定路径下的文件与目录，提供文件系统内容的概览。

### `now`

返回当前系统日期与时间。

### `open`

通过操作系统默认关联程序打开文件或URL链接。

### `read_file`

读取项目中指定文件的内容，允许访问文件内容。

### [[代码块_0]]

允许代理在处理复杂问题时进行思考、头脑风暴或制定计划，而无需执行实际操作。

### [[代码块_1]]

通过网络搜索信息，提供相关网页的摘要和链接，便于获取实时资讯。

## 编辑工具

### [[代码块_2]]

在项目中递归复制文件或目录，复制内容时比手动读写文件更高效。

### [[代码块_3]]

在项目指定路径创建新目录，同时创建所有必需的父目录（功能类似于[[代码块_4]]）。

### [[代码块_5]]

在指定路径创建包含给定文本内容的新文件，这是创建新文件或完全替换现有文件的最有效方式。

### [[代码块_6]]

删除指定路径下的文件或目录（包括递归删除所有内容），并确认删除操作。

### [[代码块_0]]

通过将特定文本替换为新内容来编辑文件。

### [[代码块_1]]

移动或重命名项目中的文件或目录，如果仅文件名不同则执行重命名操作。

### [[代码块_2]]

执行 shell 命令并返回合并后的输出结果，每次调用都会创建新的 shell 进程。
