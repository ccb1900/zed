# 图标主题

Zed 内置了一套图标主题，同时可通过扩展安装更多图标主题。

## 选择图标主题

通过图标主题选择器可查看已安装的图标主题并预览效果。您可通过命令面板中的"图标主题选择器：切换"指令打开该功能。

在图标主题列表中上下移动时，系统将实时切换图标主题，按下回车键即可将所选主题保存至设置文件。

## 安装更多图标主题

可通过扩展页面获取更多图标主题：在命令面板中执行"zed：扩展"指令，或访问[Zed官网扩展中心](https://zed.dev/extensions)。

## 配置图标主题

您选择的图标主题将存储于设置文件中。可通过命令面板的"zed：打开设置"指令（macOS系统快捷键为`cmd-,`，Linux系统为`ctrl-,`）打开设置文件。

与主题类似，Zed 允许为浅色和深色模式配置不同的图标主题。您可以将模式设置为 `"light"` 或 `"dark"` 来忽略当前系统模式。

```json [settings]
{
  "icon_theme": {
    "mode": "system",
    "light": "Light Icon Theme",
    "dark": "Dark Icon Theme"
  }
}
```
