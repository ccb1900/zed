# Zed 在 Windows 系统

## 安装 Zed

通过[下载页面](https://zed.dev/download)获取最新的稳定版本。如需下载预览版本，请访问[预览版发布页面](https://zed.dev/releases/preview)。首次手动安装后，Zed 将自动定期检查更新。

您也可以从源码编译 Zed，具体步骤请参阅[开发文档](https://zed.dev/docs/development/windows)。

## 卸载程序

- 通过安装程序安装：请使用`Settings` → `Apps` → `Installed apps`，搜索 Zed 并点击卸载。
- 从源码编译安装：请删除您创建的构建输出目录（例如 target/install 文件夹）。

您的设置和扩展配置存储于用户配置文件中。卸载时，您可以选择保留或删除这些数据。

## 远程开发 (SSH)

Zed 支持 Windows 系统的 SSH 远程开发，并在需要时提示输入认证信息。

若遇到身份验证问题，请确认您的SSH密钥代理正在运行（例如ssh-agent或Git客户端代理），并确保ssh.exe已添加到PATH环境变量中。

## WSL支持

Zed原生支持在WSL环境内直接打开文件夹。

若要在WSL容器中打开本地文件夹，请使用`projects: open in wsl`操作并选择目标文件夹，系统将显示可用WSL发行版列表供您选择。

若要打开已位于WSL容器内的文件夹，请使用`projects: open wsl`操作并选择对应发行版，该发行版将自动添加至`Remote Projects`窗口，您即可在此打开目标文件夹（详见[远程开发](./remote-development.md)文档）。

## 故障排除

### Zed启动失败或显示空白窗口

- 从您的显卡供应商（Intel/AMD/NVIDIA）更新显卡驱动程序。
- 确保在 Windows 中启用了硬件加速，且未被第三方软件阻止。
- 尝试在不加载扩展或自定义设置的情况下启动 Zed，以排查冲突。

### 终端问题

如果激活脚本未运行，请更新至最新版本，并检查您的 Shell 配置文件是否提前退出。对于 Git 操作，请确认 Git Bash 或 PowerShell 可用且已加入 PATH 环境变量。

### SSH 远程连接问题

当提示输入凭据时，请使用图形化 askpass 对话框。如果对话框未显示，请检查是否存在凭据管理器冲突，并确保终端未阻止图形界面提示。

### 图形问题

#### Zed 无法启动 / 性能下降

Zed 需要兼容 DX11 的显卡才能运行。如果 Zed 无法启动，可能是您的显卡未达到最低要求。

要检查您的显卡是否支持 DX11，可以使用以下命令：

```
dxdiag
```

这将打开诊断工具，在[[代码块_0]] → [[代码块_1]] → [[代码块_2]]下显示您的GPU支持的最低DirectX版本。

您可能也尝试在虚拟机中运行Zed，这种情况下它会使用虚拟机提供的模拟适配器。虽然Zed可以运行，但性能会有所下降。
